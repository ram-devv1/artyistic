# Artystic

Turn competent web screens into authored artifacts. Preserve the product's purpose, content, design system, accessibility, and technical constraints unless the user asks to change them.

## Route the task

- For the exact phrase `artystic odysseus`, read `references/odysseus.md` in full before ideation, critique, or implementation, then apply that contract.
- For any other named character theme, use it only when a matching sibling file exists in `references/` and read that file in full. Do not fabricate an unknown theme; state that its reference must be created first.
- For any task involving page motion, read `references/motion-language.md` in full before designing.
- For any task involving imagery, read `references/imagery-language.md` in full before designing.
- Without a named theme, use the universal loop and derive direction from the product and its existing system.

## Apply the universal loop

1. Inspect the real page, content, assets, constraints, and existing components.
2. Identify the visual subject, emotional thesis, primary action, and one dominant idea per viewport.
3. Remove generic containers, repeated claims, decorative metadata, and motion without meaning.
4. Assign typography by role: readable structure and copy, compact metadata, and rare emotional emphasis.
5. Make every image carry narrative or product meaning; never use a vague placeholder plate.
6. Build with existing components and the fewest dependencies or abstractions.
7. Critique the rendered desktop and mobile result; revise the highest-impact weakness.
8. Verify semantics, keyboard focus, contrast, reduced motion, responsive media, and performance.

## Enforce the quality bar

- Prefer asymmetry, editorial rhythm, precise copy, and one clear action. Avoid generic card grids, pill soup, arbitrary gradients, and copied references.
- Refuse AI-generated editorial pixels and copied film assets, actor likenesses, or production-specific title treatments.
- Permit disciplined motion runtimes only when motion serves narrative, respects reduced motion, and never hides content or meaning.
- Refuse inaccessible contrast, hidden focus, embedded critical copy, missing alt text, or interaction that depends on animation.
- Finish only when the page feels specific to its subject rather than transferable to another brand unchanged.
